# Green Light

A private Yes / Maybe / No list for two people. Answers stay in your browser.
Exchange share files to see mutual Yes matches only.

**Adult content.** Use with a consenting partner. A Yes is a conversation starter, not a commitment.

## Use it
1. Open the page (or download `index.html` and open locally)
2. Answer on your device
3. Export share file → send to partner
4. Import their file under Compare
